Acerca del proyecto

Proyecto final del curso de Telemática. Implementa una aplicación web con un stack completo de observabilidad desplegado en AWS usando infraestructura como código con Terraform.

Demuestra cómo instrumentar una aplicación Flask con métricas de Prometheus y visualizarlas en Grafana, todo provisionado automáticamente en una instancia EC2.
